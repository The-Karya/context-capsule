Free. No account. It updates itself.

Get started

  1. Install it. Mac: open the file and drag Karya Context Capsule to Applications. Windows: open the file. Linux: make the file executable, then open it.
  2. Open it and follow Settings. Turn on each step, and connect Claude in one click.
  3. Press Option-C (Alt+C) when you start work. At the end of the day, click Make today's capsules. Claude writes them for you.

Your privacy

Only text is kept, on your computer. No screenshots, no audio, no cloud. Read exactly what goes where.
